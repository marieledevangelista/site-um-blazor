# site-um-blazor

Projeto desenvolvido para a lista de exercícios de Blazor.

O projeto possui quatro páginas:

- Sobre: apresenta uma breve descrição pessoal.
- Contador: aumenta a quantidade de cliques em um botão.
- Mensagem: exibe e oculta uma mensagem.
- Placar: permite somar, subtrair e zerar pontos sem permitir valores negativos.
